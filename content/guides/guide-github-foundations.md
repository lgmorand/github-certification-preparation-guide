# GitHub Foundations

## Prerequisites

- Basic understanding of version control concepts
- Familiarity with software development workflows
- No prior GitHub experience required

## Skills measured

- Introduction to Git and GitHub (15%) - Approx 10 Questions
- Working with GitHub Repositories (15%) - Approx 10 Questions

## Key Concepts to Master

### Git Basics
- Understanding distributed version control
- Commits, branches, and merging
- Cloning, pushing, and pulling
- Understanding Git history and logs
- Working with .gitignore files

### GitHub Repositories
- Creating and managing repositories
- README files and documentation best practices
- Repository visibility (public, private, internal)
- Repository templates
- GitHub Archive Program

### Collaboration Features
- Pull requests and code reviews
- Issues and issue templates
- GitHub Discussions
- Mentions and notifications
- Forks and upstream repositories

### Modern Development
- GitHub Actions basics
- GitHub Codespaces overview
- GitHub Copilot introduction
- GitHub Mobile features
- Markdown syntax

### Project Management
- GitHub Projects (classic and new)
- Milestones and labels
- Task lists and checklists
- Project boards and automation
- Insights and analytics

### Security and Administration
- Two-factor authentication (2FA)
- Personal access tokens
- SSH keys
- Branch protection rules
- Security advisories basics

### GitHub Community
- GitHub Sponsors
- GitHub Stars program
- Contributing to open source
- Community health files (CODE_OF_CONDUCT.md, CONTRIBUTING.md)
- GitHub Explore and trending repositories
